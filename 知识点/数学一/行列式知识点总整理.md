# 行列式知识点总整理

面向数学一常见考点整理；不是对特定年度官方大纲逐条核验。相关速查见 [[行列式的运算法则]]。

## 一、定义与低阶计算
行列式是方阵对应的一个数；$n$阶有$n$行$n$列，不是$n$个元素，也不是矩阵。
二阶：
$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc.$$
三阶：
$$
\begin{vmatrix}a&b&c\\d&e&f\\g&h&i\end{vmatrix}
=aei+bfg+cdh-ceg-bdi-afh.
$$
三阶对角线法则不适用于四阶及以上。

### 排列、逆序数与定义式
排列：$1,\ldots,n$的一种排列顺序，数量$n!$。一对数字中前大后小即一个逆序，逆序总数$\tau$；偶数为偶排列，奇数为奇排列。交换任意两个位置改变奇偶性。
例如312有$(3,1),(3,2)$两个逆序，是偶排列。
$$\det A=\sum_{(j_1,\ldots,j_n)}(-1)^{\tau(j_1,\ldots,j_n)}
a_{1j_1}\cdots a_{nj_n}.$$
共$n!$个带符号项，每项每行每列恰取一个元素。若乘积未按行序排列，符号为$(-1)^{\tau(i_1,\ldots,i_n)+\tau(j_1,\ldots,j_n)}$。
通常不靠定义式直接计算高阶行列式。

## 二、基本性质
| 操作或条件 | 结论 |
| --- | --- |
| 转置 | $\det(A^T)=\det A$ |
| 交换两行或两列 | 变号 |
| 一行乘$k$ | 行列式乘$k$ |
| 一行加另一行的$k$倍 | 不变 |
| 某行全0 | 为0 |
| 两行相同或成比例 | 为0 |
| 各行线性相关 | 为0 |
| 一行拆为两行向量之和 | 拆成两个行列式，其他行保持不变 |

列性质同样成立。对一个行列式可先做行变换再做列变换，但不能直接将某行加到某列。
同一组多步操作应写明先后，避免把已修改的行当原行。
某行提公因子与整个矩阵乘数不同：$\det(kA)=k^n\det A$。
一般$\det(A+B)\ne\det A+\det B$。

## 三、余子式、代数余子式与展开
删除第$i$行、第$j$列，剩余行列式为余子式$M_{ij}$。
代数余子式$C_{ij}=(-1)^{i+j}M_{ij}$，符号从左上角正号开始交替。
沿行展开：
$$\det A=\sum_{j=1}^{n}a_{ij}C_{ij}.$$
沿列展开：
$$\det A=\sum_{i=1}^{n}a_{ij}C_{ij}.$$
优先选择零多的行或列。$C_{ij}$不含第$i$行、第$j$列元素。

### 异行、异列乘积之和为0
$$\sum_j a_{ij}C_{kj}=\delta_{ik}\det A.$$
$i=k$时为本行展开；$i\ne k$时为0。异列同理：
$$\sum_i a_{ij}C_{ik}=\delta_{jk}\det A.$$
不能只因出现一组代数余子式就直接判为$\det A$，先核对下标。

### 代数余子式加权求和
$$\sum_j b_jC_{ij}
=\det(\text{把A的第i行换成}(b_1,\ldots,b_n)\text{所得矩阵}).$$
因此$\sum_j C_{ij}$可把第$i$行换成全1再求行列式。列求和同理。
这里只替换展开所对应的那一行，其他行不动。
改变单一元素$a_{ij}\to a_{ij}+t$，新行列式为$\det A+tC_{ij}$。

### 拉普拉斯展开（计算工具）
选定$k$行，枚举所取$k$列，对应子式乘互补子式，符号为$(-1)^{\text{所选行号之和}+\text{所选列号之和}}$，最后求和。$k=1$就是普通展开。通常掌握结构题应用即可。

## 四、特殊结构
1. 上三角、下三角、对角：
$$\det A=\prod_i a_{ii}.$$
2. 只有副对角线非零（或其一侧全零的反三角结构）：
$$\det A=(-1)^{n(n-1)/2}\prod_i a_{i,n+1-i}.$$
3. 分块三角（$B,D$是方阵）：
$$\det\begin{pmatrix}B&C\\0&D\end{pmatrix}
=\det B\det D.$$
下分块三角同理。一般不能把矩阵块当数字套$ad-bc$。
4. 分块副对角（$B$为$p$阶，$C$为$q$阶）：
$$\det\begin{pmatrix}0_{p\times q}&B\\C&0_{q\times p}\end{pmatrix}
=(-1)^{pq}\det B\det C.$$
5. 范德蒙德：
$$
\det\begin{pmatrix}
1&x_1&\cdots&x_1^{n-1}\\
1&x_2&\cdots&x_2^{n-1}\\
\vdots&\vdots&&\vdots\\
1&x_n&\cdots&x_n^{n-1}
\end{pmatrix}
=\prod_{1\le i<j\le n}(x_j-x_i).
$$
不同转置或排序会影响写法，要核对顺序。有重复$x_i$则为0。
6. 主对角均为$a$，其余均为$b$：
$$D_n=(a-b)^{n-1}[a+(n-1)b].$$
可由行列变换推出，也可用特征值理解。
7. 常系数三对角：
主对角$a$、上对角$b$、下对角$c$时，
$$D_n=aD_{n-1}-bcD_{n-2},\quad D_0=1,\ D_1=a.$$
$D_0=1$是递推约定。

## 五、与矩阵运算的联系
对同阶$n$阶方阵：
$$
\det I=1,\quad
\det(AB)=\det A\det B,\quad
\det(kA)=k^n\det A,
$$
$$
\det(-A)=(-1)^n\det A,\quad
\det(A^m)=(\det A)^m.
$$
$m$为正整数；负整数时还要求$A$可逆。
$A$可逆时：
$$\det(A^{-1})=\frac1{\det A}.$$
相似矩阵有相同行列式。矩阵乘法通常不交换，但$\det(AB)=\det(BA)$（同阶方阵）。

### 伴随矩阵
伴随矩阵是代数余子式矩阵的转置：$(A^*)_{ij}=C_{ji}$。
$$AA^*=A^*A=(\det A)I.$$
$n\ge2$时：
$$\det(A^*)=(\det A)^{n-1}.$$
可逆时$A^*=(\det A)A^{-1}$。
常用交叉考点：
- $r(A)=n\Rightarrow r(A^*)=n$；
- $r(A)=n-1\Rightarrow r(A^*)=1$；
- $r(A)\le n-2\Rightarrow A^*=0$。

## 六、与可逆、秩、向量组和方程组的联系
对$n$阶方阵：
$$
\det A\ne0
\Longleftrightarrow A\text{可逆}
\Longleftrightarrow r(A)=n
\Longleftrightarrow \text{行/列向量线性无关}
$$
$$
\Longleftrightarrow Ax=0\text{只有零解}
\Longleftrightarrow \forall b,\ Ax=b\text{有唯一解}.
$$
$\det A=0$时：不可逆、秩小于$n$、列向量线性相关、齐次方程有非零解；非齐次方程可能无解也可能无穷多解，需比较秩。
秩是非零子式的最高阶数，矩形矩阵本身没有行列式。

### 克拉默法则
$Ax=b$且$\det A\ne0$时：
$$x_i=\frac{D_i}{\det A},$$
$D_i$是将$A$的第$i$列换成$b$所得行列式，不是换第$i$行。
若$\det A=0$，不能用克拉默除法，也不能直接认定非齐次方程无解。

## 七、特征值与其他章节的联系
特征值按代数重数计：
$$\det A=\prod_i\lambda_i.$$
$$\det(\lambda I-A)=\prod_i(\lambda-\lambda_i).$$
$\det(A-\lambda I)=(-1)^n\det(\lambda I-A)$，零点相同。
多项式$p$满足$\det p(A)=\prod_i p(\lambda_i)$。
实奇数阶反对称矩阵$A^T=-A$必有$\det A=0$：由转置不变得$\det A=(-1)^n\det A$。
正交矩阵$Q$满足$\det Q=\pm1$。
实对称矩阵正定当且仅当所有顺序主子式均大于0；仅$\det A>0$不能判断正定。这些是跨章节联系。

## 八、常见计算方法与题型
| 看到的结构 | 优先方法 |
| --- | --- |
| 低阶数字题 | 二阶公式或消元 |
| 一行/列零很多 | 展开 |
| 有倍数、相近行列 | 倍加造零、提公因子 |
| 各行和相同 | 把其他列加到一列，提出公因子后消元 |
| 幂次排列 | 范德蒙德 |
| 阶数变化但结构重复 | 递推 |
| 分块零结构 | 分块三角或拉普拉斯 |
| 抽象乘积、逆、转置、伴随 | 行列式运算公式 |
| 代数余子式加权和 | 替换对应行/列再展开 |
| 参数使方程有非零解 | 令系数行列式为0 |

消元示例：
$$
\begin{vmatrix}1&2&3\\2&5&8\\1&3&6\end{vmatrix}
\xrightarrow{R_2-2R_1,\ R_3-R_1}
\begin{vmatrix}1&2&3\\0&1&2\\0&1&3\end{vmatrix}
\xrightarrow{R_3-R_2}
\begin{vmatrix}1&2&3\\0&1&2\\0&0&1\end{vmatrix}=1.
$$
参数题不要随意除以可能为0的参数；需分类或用不含除法的变换。
例$A=\begin{pmatrix}t&1\\1&t\end{pmatrix}$，$\det A=t^2-1$，故$t\ne\pm1$可逆，$t=\pm1$不可逆。

## 九、易错清单
- 行列式是数，矩阵是表；不能把$\det A$和$A$混用。
- 倍加不变，倍乘会变；交换变号。
- $\det(A+B)$不能随意拆。
- $\det(kA)$是$k^n$倍。
- 余子式与代数余子式差符号。
- 副对角结构注意$(-1)^{n(n-1)/2}$。
- 三阶对角线法不能推广高阶。
- $\det A=0$不等于$A=0$。
- $AB=0$可推出$\det A\det B=0$，但不能推出$A=0$或$B=0$。
- 乘积行列式为0意味着至少一因子矩阵奇异，不是至少一个因子为零矩阵。
- 绝对值记号$|\det A|$与矩阵行列式记号$|A|$要看上下文区分。
- 全部子式、主子式、顺序主子式不是同一概念：主子式选相同行列指标，顺序主子式取左上角前$k$行列。

## 十、复习顺序
先熟练性质与消元，再学展开及代数余子式求和，再记矩阵公式，最后做特殊结构和跨章节综合。
自测：能否解释倍加不变？能否识别余子式求和对应替换哪一行？能否判断参数为0时变换是否合法？

## 补充：分块三角什么时候变号
主对角分块上/下三角都直接相乘，不额外变号：
$$
\det\begin{pmatrix}B&C\\0&D\end{pmatrix}
=\det\begin{pmatrix}B&0\\C&D\end{pmatrix}
=\det B\det D.
$$
这里B为p阶、D为q阶方阵，C的尺寸随结构匹配。左下为0与右上为0均不影响符号规则。

若非零方块在副对角位置，如B为p阶、D为q阶：
$$
\det\begin{pmatrix}0_{p\times q}&B\\D&C\end{pmatrix}
=(-1)^{pq}\det B\det D.
$$
把左边q列整体移到右边，跨过p列，需要pq次单列交换，才变成主对角分块三角。因此pq为奇数才额外变号，即p、q都为奇数；至少一个为偶数则不变号。C为q×p矩阵，可以非零。
同理，当右下为零、另外两个副对角方块为B、D时也有此符号，需注意分块尺寸。
整体交换两块行/列不是必然一次变号，要数实际单行/单列交换次数。
例p=q=1，|0 b; d c|=-bd；p=1,q=2，因(-1)^2=1不额外变号。
主对角分块乘积自身可为负，这不同于公式额外乘负号。
